# 快速拨号盘 (Speed Dials)

The `v-speed-dial` component can be used as a floating action button that can reveal additional actions when clicked.

<PageFeatures />

::: success

此特性在 [v3.6.0](/getting-started/release-notes/?version=v3.6.0) 引入。

:::

## 使用

快速拨号可以附加到材料上，以表示应用程序中的推广操作。大多数情况下都会使用默认尺寸，但也可以使用“小”变体来保持类似尺寸元素的连续性。
