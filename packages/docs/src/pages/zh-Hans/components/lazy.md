# 懒加载 (Lazy)

`v-lazy` 组件用于根据元素的可见性动态加载组件。

<PageFeatures />

## 使用

`v-lazy` 组件在默认情况下，除非组件出现在视口中，否则是不会渲染其中的组件的。在例子中，向下滑动，观察当元素出现在视口中时的渲染。
