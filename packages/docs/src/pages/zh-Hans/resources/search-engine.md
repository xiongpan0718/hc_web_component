# 搜索引擎

添加 Vuetify 作为快速访问文档的浏览器搜索引擎。

<PageFeatures />

<PromotedEntry />

## 起步

可以使用 Vuetify 文档作为浏览器的搜索引擎。这样可以让您在浏览器的地址栏直接搜索而不必先访问 Vuetify 的网站（就是这个）。要添加 Vuetify 作为搜索引擎，可以按下面的步骤进行：

### 谷歌 Chrome

1. 打开 Chrome 设置 ![图片](https://github.com/vuetifyjs/vuetify/assets/9064066/3b83a0a1-a51d-4c88-bf1b-0200a1f6b532)
2. 搜索"管理搜索引擎和网站搜索" ![搜索](https://github.com/vuetifyjs/vuetify/assets/9064066/8fd8f1e4-ebed-4c8a-9444-16163c580a60)
3. 向下滚动到“站点搜索”，然后点击 <v-kbd>添加</v-kbd> 按钮以增加一个新的搜索引擎 ![图片](https://github.com/vuetifyjs/vuetify/assets/9064066/87d7775f-0f92-4f12-b9dd-01195f80df31)
4. 在“添加搜索引擎”对话框中输入以下信息：

* 搜索引擎： `Vuetify` { .ms-4 }
* 快捷字词：`vt`（或者其他你喜欢的短语）{ .ms-4 }
* 网址格式（用“%s”代替搜索字词）: `https://vuetifyjs.com/?search=%s` { .ms-4 }

5. 单击 <v-kbd>添加</v-kbd> 按钮保存搜索引擎
6. 打开您的浏览器并输入 `vt` 到网址栏，然后按空格或Tab键： ![图片](https://github.com/vuetifyjs/vuetify/assets/9064066/07869a65-bcc4-44c2-a900-3f69eea1be4b)
7. 输入您的搜索查询，然后按 Enter 键来搜索 Vuetify 文档 ![图片](https://github.com/vuetifyjs/vuetify/assets/9064066/e91092f4-f308-4ed4-9b4a-33ac189aec19)

### Edge 浏览器

1. 打开 Edge 的设置 ![步骤1](https://github.com/vuetifyjs/vuetify/assets/9064066/696182cf-5eab-4229-a007-5521186f8058)
2. 搜索“地址栏和搜索” ![边缘搜索](https://github.com/vuetifyjs/vuetify/assets/9064066/9b9487c3-34d6-44b4-81e2-45ba30da2977)
3. 点击 <v-kbd>添加</v-kbd> 按钮以增加一个新的搜索引擎 ![步骤2](https://github.com/vuetifyjs/vuetify/assets/9064066/eb50602a-bb6d-4933-92cd-e4f0edbc8a86)
4. 在“添加搜索引擎”对话框中输入以下信息：

* 搜索引擎： `Vuetify` { .ms-4 }
* 快捷字词：`vt`（或者其他你喜欢的短语）{ .ms-4 }
* 网址格式（用“%s”代替搜索字词）: `https://vuetifyjs.com/?search=%s` { .ms-4 }

![添加搜索引擎](https://github.com/vuetifyjs/vuetify/assets/9064066/8b31e827-5b16-4ba8-b220-bcbe139986ff)

5. 单击 <v-kbd>添加</v-kbd> 按钮保存搜索引擎
6. 打开您的浏览器并输入 `vt` 到网址栏，然后按空格或Tab键： ![搜索栏](https://github.com/vuetifyjs/vuetify/assets/9064066/59311829-e564-4c80-a0c9-d33e7aacfd21)
7. 输入您的搜索查询，然后按 Enter 键来搜索 Vuetify 文档 ![步骤5](https://github.com/vuetifyjs/vuetify/assets/9064066/8245afd9-bceb-41dd-8310-50e4137d1fca)
