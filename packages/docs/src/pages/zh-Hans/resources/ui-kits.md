## 使用

Vuetify UI 套件是Figma 的免费组件插件，用于简化应用程序的构建。

### Figma 插件

使用 Vuetify UI 套件的最快和最简单的方法是将其安装为 [Figma 的插件](https://www.figma.com/community/file/1266515419060480209)。

### 数字下载

如果您因任何原因需要手动安装该插件，可以从 [Vuetify 商店](https://store.vuetifyjs.com/)下载最新版本。

1. 免费从我们的商店[下载](https://store.vuetifyjs.com/products/vuetify-ui-kit-figma)
2. 从 `vuetify-figma-ui-kit.zip` 中解压 **vuetify3-ui-light-kit.fig**
3. 打开 Figma 并创建一个新项目： ![UI 套件新建项目](https://cdn.vuetifyjs.com/docs/images/ui-kits/ui-kit-new-project.png)
4. 选择 **Import file** 并导航到您解压 `vuetify3-ui-light-kit.fig` 文件的位置： ![UI 套件导入文件](https://cdn.vuetifyjs.com/docs/images/ui-kits/ui-kit-import-file.png)
5. 创建一个新的设计文件： ![UI 套件新建设计文件](https://cdn.vuetifyjs.com/docs/images/ui-kits/ui-kit-new-design-file.png)
6. 在您的项目中访问组件，请选择 **Assets** 并搜索所需的组件： ![UI 套件搜索资源](https://cdn.vuetifyjs.com/docs/images/ui-kits/ui-kit-search-assets.png)
