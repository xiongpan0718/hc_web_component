# 长期支持

Vuetify 为上一个主要版本提供为期 18 个月的长期支持，以修复关键错误和安全漏洞。

<PageFeatures />

<VoPromotionsCardVuetify />

我么明白许多使用 Vuetify 的项目都有开发周期，以致于无法使用最新的版本。为了让开发者和企业在采用 Vuetify 时安心，我们承诺为上一个 _主要版本_ 的最新 _次要版本_ 提供至少 **18个月** 的关键错误和安全漏洞修复。

| 版本                                        | 支持状态   | 初始发布日期     | 长期支持开始日期       | 长期支持结束日期        |
| ----------------------------------------- | ------ | ---------- | -------------- | --------------- |
| [Vuetify 3.x](https://vuetifyjs.com/)     | 🚀 活跃开发 | 2022年11月1日 | 无              | 无               |
| [Vuetify 2.7](https://v2.vuetifyjs.com/)  | 🛠️ 维护  | 2019年7月23日 | 2023 年 7 月 5 日 | 2025 年 1 月 23 日 |
| [Vuetify 1.5](https://v15.vuetifyjs.com/) | 📦 已归档  | 2019年2月5日  | 2019年7月31日     | 2020年7月31日      |

有问题吗？可以在我们的 [Discord 社区](https://community.vuetifyjs.com)联系我们。

::: tip
Vuetify团队为注册企业支持的用户专门打造服务计划。立即 [预约咨询](/introduction/enterprise-support/)吧！
:::
