## 什么是 Vuetify？

自从 2014 年释出初版后，[Vue.js](https://vuejs.org/) 迅速成长为世界上最受欢迎的 JavaScript 框架。之所以受欢迎的原因之一莫过于对于[组件](https://vuejs.org/guide/essentials/component-basics.html)的广泛使用，即为开发者创建于某个应用中可重用的小模块。Vuetify 由一些拥有丰富而强大的特性的，预定义组件组成。这些特性包括例如 [动态主题](/features/theme/)、[全局默认值](/features/global-configuration/)、[应用框架](/features/application-layout/) 等等构成。它以提供给开发者丰富的工具，给用户良好而丰富的使用体验为最终目标。

## 为什么选择 Vuetify { id="why-vuetify" }

Vuetify 是一个功能强大的 Vue 组件框架，从底层开始构建，易学易用。我们的 UI 组件集合可在您的应用程序中保持一致的风格，并提供足够的自定义选项以满足任何使用情况。

### 免费 { id="its-free" }

Vuetify 是一个开源项目，根据 [MIT licensed](http://opensource.org/licenses/MIT) 授权免费提供。此外，Vuetify 的源代码可在 GitHub 上获取，开发人员可根据自己的选择进行修改并为其开发做出贡献。

### 灵活的组件

Vuetify 中的每个组件都是根据 Google 的 [Material Design 规范](https://material.io/) 手工制作的，并提供数百个自定义选项，适合任何风格或设计。即使不是 Material Design也是如此。只需使用**props**、**slots（插槽）** 和 **components（组件）**，或将它们结合使用，就能随心所欲地编写简洁或冗长的 Vue 模板。

### 工具

Vuetify 拥有庞大开发工具生态，覆盖了从项目创建到 UI 设计工具包一整套开发体验。

* 🎨 [Figma UI 组件套件](https://store.vuetifyjs.com/products/vuetify-ui-kit-figma)
* [第一方 Vite 支持](https://github.com/vuetifyjs/vuetify-loader/tree/master/packages/vite-plugin)
* 🏗️ [为TypeScript 和 JavaScript 预配置的 Vue 3 应用程序](https://tryvuetify.com)
* 对 [VSCode](https://code.visualstudio.com/docs/editor/intellisense) 和 [JetBrains](https://www.jetbrains.com/help/rider/Auto-Completing_Code.html) 产品的智能感知和自动完成支持
* 🖼️ [预置布局示例](/getting-started/wireframes/)

### 社区

与 Vuetify 一起开发，您永远不会孤单。遇到问题束手无策？利用我们庞大的 [Discord 社区](https://community.vuetifyjs.com/)，在我们的公共帮助频道中与其他 Vuetify 开发人员合作。需要更个性化的支持解决方案？Vuetify 提供针对个人和企业的 [企业支持](/introduction/enterprise-support/)。查看 [赞助 Vuetify 开发](/introduction/sponsors-and-backers/) 的其他方式。

### 专业人员和企业支助

Vuetify 提供一系列支持服务，旨在帮助您充分利用您的应用程序。让我们经验丰富的团队为您提供成功所需的工具：

* ↗️ Vuetify 版本升级
* 📊 性能审查 & 分析
* ⛑️ SLA & 直接支持

欲了解更多关于我们专业支持选项的信息，请浏览到我们的 [企业支持](/introduction/enterprise-support/) 页面。

### 活跃开发

自 2016 年以来，Vuetify 一直在积极开发中，并不断以极快的速度响应社区问题和报告，让您能够更频繁地获得错误修复和增强功能。我们的总体发布节奏通常如下：

* 🔨 补丁**(每周)**
* ⛏️ 次要版本 **(每季度)**
* ⚒️ 主要版本** (每两年一次至每年一次)**

此外，在每次主要版本发布后，先前的版本仍然保持 18 个月[长期支持](/introduction/long-term-support/) 。
